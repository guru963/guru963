### [ISL Translator](https://github.com/guru963/ISL) — Speech to Indian Sign Language
![Accessibility](https://img.shields.io/badge/ACCESSIBILITY-58A6FF?style=flat-square) ![Real-Time](https://img.shields.io/badge/REAL--TIME-3fb950?style=flat-square)

Converts English speech from video into Indian Sign Language using a grammar-aware NLP pipeline. Restructures English into ISL syntax (SOV order) — not word-for-word. Includes a real-time translation mode.

Pipeline: `Video` → `Whisper` → `spaCy NLP` → `ISL Grammar Reorder` → `Video Stitch` → `ISL Output`

![Whisper](https://img.shields.io/badge/Whisper-412991?style=flat-square&logo=openai&logoColor=white) ![spaCy](https://img.shields.io/badge/spaCy-09A3D5?style=flat-square) ![OpenCV](https://img.shields.io/badge/OpenCV-5C3EE8?style=flat-square&logo=opencv&logoColor=white) ![FFmpeg](https://img.shields.io/badge/FFmpeg-007808?style=flat-square&logo=ffmpeg&logoColor=white) ![Docker](https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white) ![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=flat-square&logo=streamlit&logoColor=white)
